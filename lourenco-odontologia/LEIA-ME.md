# Lourenço Odontologia & Estética

## Abrir no VS Code
1. Extraia o ZIP.
2. No VS Code, use Arquivo > Abrir Pasta e selecione esta pasta.
3. Abra index.html com a extensão Live Server (Open with Live Server). Também é possível abrir index.html diretamente no navegador.

Não precisa instalar Node.js ou executar npm.

## Arquivos
- index.html: página inicial.
- sobre.html: página Sobre.
- styles.css: layout, responsividade e animações.
- app.js: menu, animações de rolagem, galeria e janela de avaliação.
- assets/: imagens locais.
